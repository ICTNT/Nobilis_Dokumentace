Správce Serveru - AD ( Active Directory )

Na serveru běží služby DNS, DHCP, AD

Uživatelé a počítače služby Active Directory :

Založení nového uživatele jako novou položku nebo kopii podobného uživatele do správné skupiny

Vyplnit jméno, heslo a následně doplnit další údaje.

Vlastnosti záložek :

obecné : jméno, email, telefon

účet : možnosti změna hesla

profil : doplnit Spolecna_YaZ.bat ( grafika.bat - jen určeným uživatelům )

telefon : doplnit

Organizace : Funkce, společnost, podřízení

Je členem :

Domain Users, Office Sync ( pro všechny uživatele )

Remote Deskop User Nobilis pro aktivaci VM2

\\vm3\NETLOGON
